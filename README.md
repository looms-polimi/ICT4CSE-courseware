# ICT4CSE courseware

This repository contains the teaching material for **ICT for Control Systems Engineering**, taught at Politecnico di Milano, Italy, within the MSc programme in Automation and Control Engineering.

Material is organised by academic year and may include lecture notes, slides, exercises, assignments, examples, and other course resources. The accompanying software library is maintained separately in the [`ICT4CSE`](https://github.com/looms-polimi/ICT4CSE) repository.
